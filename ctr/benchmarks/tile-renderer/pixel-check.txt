# Pixel-equivalence variants (tools/build_pixel_check.sh, tools/emu_pixel_check.py).
# Format: <name>|<extra -D flags>|<reference>   Each is built with BENCH_AUTO=1 BENCH_DUMP_FRAME=300 and dumps both
# screens (raw RGB8) after the simulation freezes at frame 300. <reference> is the variant its pictures are
# compared with; "-" marks a reference itself. The simulation is deterministic, so identical scenes must give
# identical pixels unless the strategies really draw differently.
